# Criteria Mapping — Internal Reference

**Not for judges.** This is a team working document showing which paragraph/slide
answers which of Amex's four scoring criteria, so we can defend the submission on
the spot if asked. Nothing here should be pasted into the actual submission — real
submissions that annotate themselves with "this paragraph proves Relevance" read as
unconfident, not thorough.

Innovation · Implementation & Impact.

## Where each criterion is strongest / weakest

- **Relevance** — strong. Section 2 explicitly enumerates the 5 required
  capabilities and maps one-to-one to what's built.
- **Idea Articulation** — strong. Sections 1/3 plus Slides 1–3 are unusually
  concrete for Round 1 (named components, not just aspiration).
- **Technical Solution & Innovation** — strong, and now honestly bounded: the
  ABAC→RBAC and Merkle→hash-chain corrections mean every technical claim in the
  doc matches what's actually running, which is a defensible position if a judge
  asks a pointed technical question.
- **Implementation & Impact** — this is where Round 1 Progress (§10 / Slide 10)
  earns its keep: most Round 1 submissions in this category will be idea-only, so
  a working, twice-verified demo is a genuine differentiator here. The one soft
  spot is **quantified success metrics** — see the checklist's gap note.
