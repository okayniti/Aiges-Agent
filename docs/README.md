# docs

Architecture and design write-ups for AegisAgent. Start with `architecture.md` for the
request flow and a description of what each service does. `deployment.md` covers
putting the whole stack on the public internet for free (Vercel + Koyeb + Upstash +
Supabase), including why each host was picked and what free-tier limits actually apply.

Kept in sync with what's actually built, not the eventual target state.
